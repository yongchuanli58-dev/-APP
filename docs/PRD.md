# 《宽带线索商机》产品需求文档（PRD）

> - 版本：v1.0（第一版开发依据）
> - 状态：已与需求方确认，进入开发阶段
> - 更新日期：2026-11-17
> - 技术形态：手机浏览器 / 微信打开即用的轻量应用（免安装、免登录），数据存储于各用户手机本地

---

## 1. 产品目标与使用场景

### 1.1 背景与痛点

- 一线宽带/专线营销师傅在日常上门、走访过程中会接触大量潜在客户，但缺少统一的记录工具，线索散落在头脑、纸片或聊天记录里，容易丢失、难以统计。
- 收集到的商机缺乏结构化梳理（客户类型、在用运营商、资费、回流意愿等），无法支撑后续持续营销，专线宽带市场份额提升缺少数据抓手。

### 1.2 产品目标

1. 为一线师傅提供一套**手机端即开即用的商机收集工具**，快速、结构化地录入宽带线索商机。
2. 提供**多维统计**（在用运营商、资费区间、客户类型、时间维度），支撑下周、下月及今后的持续跟进营销，助力提升移动公司专线宽带市场份额。
3. 支持**就地跟进动作**：一键拨打客户电话、一键导航到客户位置。
4. 支持**模板分享**：同事之间可互相分享空白模板各自建库，商机数据彼此隔离、不泄露。
5. 支持**Excel 导出**：一键导出本机商机清单，便于上报与汇总。

### 1.3 目标用户

| 角色 | 说明 |
|---|---|
| 一线营销师傅 | 主要用户，使用手机完成商机录入、跟进、统计、导出 |
| 营销/装维主管 | 接收下属导出的 Excel 清单做汇总分析（被动使用） |
| 同事（被分享者） | 通过分享链接获得空白模板，各自建立自己的商机库 |

### 1.4 核心使用场景

| 场景 | 流程概述 |
|---|---|
| 上门/走访中录入 | 到达客户处 → 打卡定位 → 填写客户类型/在用运营商/资费/客户信息 → 保存 |
| 后续跟进回访 | 打开清单 → 一键拨打客户电话 / 一键导航到客户位置 → 查看详情 |
| 营销数据盘点 | 统计页按运营商、资费区间、客户类型、时间查看线索分布，指导下周/下月营销 |
| 数据上报 | 导出 Excel 清单，通过微信等渠道发送给上级/同事 |
| 团队推广 | 「我的」页分享空白模板给同事，同事扫码/点链接后建立自己的空商机库 |

### 1.5 技术形态与数据机制（已确认决策）

| 决策项 | 结论 |
|---|---|
| 形态 | 链接 / 二维码打开即用，无需安装 App；安卓、iOS、鸿蒙手机浏览器或微信内均可打开 |
| 登录 | 不需要登录，打开即用 |
| 数据存储 | 存于各用户手机本地（浏览器本地存储），刷新、关闭、重启不丢失 |
| 数据隔离 | 不同用户各存各的，互相不可见；分享出去的模板为空白版本，不携带任何商机数据 |
| 定位 | 高德开放平台 Web 端 Key（用户已申请完成），调用高德定位组件完成打卡定位 |
| 分享托管 | 部署于免费静态托管平台（见 1.6），线上链接长期有效 |
| Excel 导出 | 前端本地生成 .xlsx 文件并触发下载，列字段已确认（见 5.3 附录） |

### 1.6 分享链接托管方案（推荐）

| 优先级 | 平台 | 说明 |
|---|---|---|
| 首选 | GitHub Pages | 免费、自带 HTTPS、无限流量、部署简单；需要注册一个 GitHub 账号，并把代码推送到仓库后开启 Pages |
| 备选 | Cloudflare Pages | 免费、自带 HTTPS；若 GitHub 访问不便可选用 |
| 兜底 | 公司内网服务器/已批准平台 | 若公司网络无法访问海外站点，则改用公司提供的服务器或经批准的平台承载，实施时与用户确认 |

> 备注：免费海外静态托管在国内访问速度不保证始终理想，但不影响功能使用；如后续实际访问不畅，再迁移到公司内部承载。此事项列入实施阶段处理。

## 2. 整体页面框架与导航结构

### 2.1 全局导航

采用**底部 4 Tab 导航**，在任何主页面均可见、可切换：

```
┌─────────────────────────────┐
│  (顶部页头，各页自定义)       │
│                             │
│                             │
│           页面内容区          │
│                             │
│                             │
├─────────────────────────────┤
│  ① 商机首页 │ ② 录入 │ ③ 统计 │ ④ 我的 │
└─────────────────────────────┘
```

| Tab | 名称 | 缺省图标 | 职责 |
|---|---|---|---|
| ① | 商机 | 清单 | 商机清单 + 概览 + 搜索 + 跟进操作入口 |
| ② | 录入 | 加号 | 打卡定位 + 录入商机（核心录入页） |
| ③ | 统计 | 图表 | 多维统计 + 导出入口 |
| ④ | 我的 | 人形 | 数据管理 + 分享模板 + 帮助 |

### 2.2 页面清单与路由

| 编号 | 页面 | 入口 | 说明 |
|---|---|---|---|
| P1 | 商机首页 | 默认页 / Tab① | 清单 + 概览 |
| P2 | 商机录入 | Tab② / 详情页「编辑」 | 新增或编辑商机 |
| P3 | 商机详情 | 首页点卡片 | 查看/编辑/删除、拨打、导航 |
| P4 | 统计中心 | Tab③ | 多维统计 |
| P5 | 我的 | Tab④ | 数据管理/分享 |
| P6 | 分享预览 | 我的 → 分享给同事 | 生成空白模板二维码/链接 |
| P7 | 引导 / 空态 / 异常 | 首次打开 / 各页空数据 / 失败 | 全局辅助页 |

### 2.3 页面间跳转关系

```
首次打开 → P7 引导 → P1 首页
P1 首页 ──点卡片──▶ P3 详情
P1 首页 ──Tab──▶ P2 录入 / P4 统计 / P5 我的
P3 详情 ──编辑──▶ P2 录入（编辑模式，预填）
P5 我的 ──分享──▶ P6 分享预览
P6 ──同事扫码/点链接──▶ 新用户 P7 引导 → 自己独立的 P1 首页
```

### 2.4 底部 Tab 切换交互规则

- 当前所在 Tab 高亮，切换即切换页面视图（单页应用内视图切换，无页面跳转刷新）。
- 录入 Tab（②）在首页与详情页均显示为「➕」样式，点击进入空白录入表单。
- 从详情页「编辑」进入录入页时，Tab ② 显示为编辑态，保存后返回详情/列表。

## 3. 首页内容结构（P1 商机首页）

### 3.1 首页布局（从上到下）

```
┌─────────────────────────────┐
│ 宽带线索商机        [搜索][…] │  ← 页头
├─────────────────────────────┤
│ 今日 8 │ 本周 23 │ 总 156    │  ← 概览卡片（3 数字）
├─────────────────────────────┤
│ [全部][今天][本周][已回访]…   │  ← 筛选 chips（横向滑动）
├─────────────────────────────┤
│ ┌─ 客户卡片1 ────────────┐  │
│ │ 王记餐馆 [中小企业][移动]│  │
│ │ 68元/月 · 建设路88号    │  │
│ │ [📞拨打客户] [🧭点击导航] │  │
│ └──────────────────────┘  │
│ ┌─ 客户卡片2 ────────────┐  │
│ │ ……                     │  │
│ └──────────────────────┘  │
│ ……（懒加载，滚动加载更多）  │
├─────────────────────────────┤
│  ① 商机 │ ②录入 │ ③统计 │ ④我的 │
└─────────────────────────────┘
```

### 3.2 页头

- 左侧：标题「宽带线索商机」。
- 右侧：搜索按钮（进入搜索态）、更多按钮（预留）。

### 3.3 概览卡片（3 个数字）

| 指标 | 定义 |
|---|---|
| 今日线索 | 今天 0:00–23:59 录入的商机条数 |
| 本周线索 | 本周一至现在的录入条数 |
| 线索总数 | 本机累计商机总条数 |

- 点击任一数字块，可跳转统计页对应维度（第一版可只做提示，可不跳转）。

### 3.4 商机清单（核心内容）

**列表项卡片展示字段：**

| 字段 | 展示方式 |
|---|---|
| 客户名称 | 主标题（加粗） |
| 客户类型 | 彩色徽标（政府/中小企/个体/家庭） |
| 在用运营商 | 徽标（移动/联通/电信/广电，可多个） |
| 资费金额 | 「68 元/月」样式 |
| 打卡位置 | 地址摘要（如「××区××路 88 号」） |
| 录入时间 | 相对时间（刚刚 / x分钟前 / 昨天 / y月z日） |

**卡片操作：**

| 操作 | 交互 |
|---|---|
| 拨打客户 | 弹确认 → 调起系统拨号盘，号码自动带入 |
| 点击导航 | 弹确认 → 打开高德导航（App 优先，未装则网页版）到客户位置 |
| 点击卡片主体 | 进入详情页 P3 |
| 左滑卡片 | 露出「删除」，二次确认后删除 |

### 3.5 列表筛选与搜索

- **筛选 chips**：全部 / 今天 / 本周 / 已回访 / 未回访（横向滑动选择）。
- **搜索**：顶部搜索框，支持按客户名称 / 电话 / 地点关键字过滤，实时匹配。
- **无结果空态**：显示引导「没有找到相关商机」。

### 3.6 空状态

- 无任何商机时显示插画提示：「还没有商机，点下方【录入】开始记录第一条」。

## 4. 第一版必须完成的功能

### 4.1 商机录入（P2）

- [ ] 高德地图打卡定位：点击打卡 → 定位成功显示 省市区+详细地址 + 定位时间；失败可重试，允许手动编辑/填写地址兜底
- [ ] 客户类型单选（政府事业单位 / 中小企业 / 个体工商户 / 个人家庭，必填）
- [ ] 客户业务当前使用情况多选（移动 / 联通 / 电信 / 广电，可多选，可空）
- [ ] 客户当前使用资费：套餐名称（文本框，可空）、套餐金额（数字，可空）
- [ ] 客户信息：名称（必填）、联系电话（必填，手机号校验）、性别（男/女，可选）、回流意愿、备注（可选，自由文本）
- [ ] 保存校验：必填项未填 → 红字提示并定位到未填项；保存成功提示并返回首页
- [ ] 支持从详情页进入编辑模式（预填已有数据）

### 4.2 商机清单与跟进（P1、P3）

- [ ] 商机列表：倒序展示、卡片字段完整、相对时间
- [ ] 拨打客户：确认后调起系统拨号盘
- [ ] 点击导航：确认后打开高德导航（App 或网页）
- [ ] 商机详情页：完整展示 + 编辑 + 删除（二次确认）
- [ ] 搜索：按名称/电话/地点过滤
- [ ] 筛选：全部/今天/本周
- [ ] 左滑删除（二次确认）

### 4.3 统计中心（P4）

- [ ] 按运营商统计：移动/联通/电信/广电在用条数，标注多选可叠加
- [ ] 资费区间统计：自定起止金额 → 显示区间内条数、月费合计、平均月费、区间明细列表；保留最近查询区间
- [ ] 按客户类型统计：4 类客户条数
- [ ] 时间维度：今日/本周/本月录入数，近 7 天录入趋势（条形图）
- [ ] 数据变动后重新进入自动刷新

### 4.4 分享空白模板（P5、P6）

- [ ] 「我的」页提供「分享给同事」入口
- [ ] 分享预览页生成空白模板链接 + 二维码
- [ ] 分享方式：微信扫码 / 复制链接 / 系统分享，三选
- [ ] 明确展示安全说明：「分享的是空白模板，不含你的商机数据」
- [ ] 同事打开获得全新的空商机库（数据完全隔离，验收入口见 5.5）

### 4.5 数据与导出

- [ ] 本地持久化：所有商机存于用户手机本地，刷新、关闭、重启不丢失
- [ ] 导出 Excel：从「我的」或「统计」页一键导出本机全部商机为 .xlsx，列字段见 5.3 附录
- [ ] 清空数据（危险操作，二次确认 + 输入「清空」确认）
- [ ] 各用户数据隔离（本地键名区分；不同设备互不可见）

### 4.6 全局与兼容

- [ ] 安卓 / iOS / 鸿蒙 手机浏览器与微信内打开均可用
- [ ] 首次打开引导页（3 步）+ 空态、异常提示
- [ ] 移动端适配（安全区、触控热区 ≥ 44px、中文字体、1010px 以内均可用）
- [ ] 高德 Web 定位 Key 正确配置（不硬编码风险、可替换）

## 5. 可以实际检查的验收标准

> 说明：以下每条均可用真机（或手机模拟器/浏览器开发者工具移动视图）实际动手检查。逐条打勾通过视为第一版达标。
