# 《宽带线索商机》部署与分享说明

> 本文档说明如何把应用部署到免费静态托管平台，生成长期有效的分享链接，并配置高德定位。

---

## 1. 部署目标（选一）

| 优先级 | 平台 | 说明 |
|---|---|---|
| 首选 | GitHub Pages | 免费、HTTPS、无限流量 |
| 备选 | Cloudflare Pages | 免费、可绑域名 |
| 兜底 | 公司内网服务器 | 若无法访问海外站点 |

---

## 2. GitHub Pages 部署步骤（首选）

### 前提
- 注册一个 GitHub 账号（github.com）

### 步骤

1. **登录 GitHub**，点击右上角「+」→「New repository」新建仓库
   - Repository name：`broadband-leads`（可自定义）
   - 选择 **Public**（Public 仓库才可免费开 Pages；Private 需付费）
   - 不要勾选「Add a README」（保持空仓库）

2. **上传项目文件**

   Windows 推荐方式（Git Bash）：
   ```bash
   cd 项目目录
   git init
   git add .
   git commit -m "宽带线索商机 v1.0"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/broadband-leads.git
   git push -u origin main
   ```

   或直接在 GitHub 网页仓库页面点「uploading an existing file」逐个上传文件（注意保持目录结构，不要传 node_modules/temp）。

3. **开启 Pages**
   - 仓库页面 → **Settings** → 左侧 **Pages**
   - Source 选择 `Deploy from a branch`
   - Branch 选 `main` + `/ (root)`
   - 点 **Save**
   - 等待 1–3 分钟，页面顶部出现：
     `Your site is published at https://<用户名>.github.io/broadband-leads/`

4. **验证**
   - 手机浏览器打开该地址 → 应看到「宽带线索商机」首页/引导页
   - 里面的链接（如 `https://<用户名>.github.io/broadband-leads/`）即为**分享给同事的模板链接**

---

## 3. 配置高德定位 Key（必做）

应用定位依赖高德开放平台 Web 端 JS API。**必须替换 Key 并把部署域名加入白名单**，否则定位报 `INVALID_USER_DOMAIN`。

### 3.1 填入 Key

编辑 `config/amap-key.js`：

```js
window.AMAP_CONFIG = {
  key: "你在高德控制台复制的JS-API-Key",
  securityJsCode: "高德安全密钥jscode",
  timeout: 10000
};
```

### 3.2 加域名白名单

> ⚠️ **最容易填错的一步**：白名单填「协议+域名」**即可，不要带后面的路径和仓库名**。
> 比如您的网页地址是 `https://yongchuanli58-dev.github.io/broadband-leads/`，
> 白名单**只填** `https://yongchuanli58-dev.github.io`（不带 `/broadband-leads`）。
> 填带路径的（如 `https://yongchuanli58-dev.github.io/broadband-leads`）会报 `INVALID_USER_DOMAIN`。

1. 登录 [高德开放平台控制台](https://console.amap.com/)
2. 应用管理 → 我的应用 → 找到 Key 所在应用
3. 点 **设置**（在 Key 右侧）→ 添加**域名白名单**
4. 填入：`https://<用户名>.github.io`
   - 例如你的用户名是 `yongchuanli58-dev`，就填 `https://yongchuanli58-dev.github.io`
   - 如果部署到别处，填对应的部署域名（如 `https://app.example.com`，同样不带路径）
   - 若一个账号下有多个 Key 或换了 Key，**确保当前使用的 Key 的白名单**包含此域名
5. 保存，等待生效（一般立即生效）

### 3.3 验证

- 手机打开线上地址 → 「录入」页 → 点【打卡】
- 弹出定位授权 → 允许 → 显示具体地址即成功
- 若仍失败，访问 `https://<用户名>.github.io/broadband-leads/diag.html` 一键诊断（会显示每步状态）

## 4. 分享给同事

1. 任意手机打开线上地址 → 底部「我的」→「分享给同事」
2. 页面显示分享链接（纯地址，不含任何数据）
3. 选择：复制链接 / 系统分享
4. 同事在微信/浏览器打开该链接 → 首次进入引导 → 建立**自己的空白商机库**
5. **数据隔离**：同事录入的数据只存在他手机，与你的数据完全分离

> 说明：分享采用「复制链接 / 系统分享」方式，不生成二维码。如需二维码给同事扫码，可用「微信扫一扫 → 输入网址」或手机浏览器内置的「网页转二维码」功能。

## 5. 安装为手机 APP（PWA「添加到主屏幕」）

应用已支持 PWA，可像原生 APP 一样安装到手机桌面，全屏打开、带独立图标，不用每次开网址。

**安卓（Chrome/系统浏览器）**
1. 用 Chrome 打开应用地址
2. 等页面加载完，点右上角菜单（⋯）
3. 点「**添加到主屏幕**」
4. 确认名称「宽带线索商机」→ 添加
5. 桌面出现蓝色图标，点开就是独立全屏应用

**iPhone（Safari）**
1. 用 Safari 打开应用地址
2. 点底部「分享」按钮（方框箭头）
3. 点「**添加到主屏幕**」
4. 确认名称 → 添加
5. 桌面出现图标，点开全屏运行

> 提示：
> - 首次安装后建议联网打开一次（完成资源缓存），之后**断网也能打开页面**查看已录数据（定位/导航/导出等需网络的提示照常）
> - 安装的是「应用外壳」，数据仍存手机本地；换手机/卸载会清数据，记得定期在「我的」页导出备份
> - 微信内右上角「在浏览器打开」后再安装，效果最好

---

## 6. 数据备份提醒

- 手机端数据存本地浏览器。**为避免误清缓存丢失**，建议定期到「我的」→「导出 Excel 清单」备份。
- 也可用「备份数据(JSON)」导出完整备份，换手机或重装时用「导入备份」恢复。

---

## 7. 常见问题

| 问题 | 处理 |
|---|---|
| 定位报 INVALID_USER_DOMAIN | 高德 Key 白名单未配置或域名不一致，按第 3 节配置 |
| 同事打开是空白（正常） | 分享的本来就是空白模板，各自建库 |
| 手机刷新后数据还在吗 | 在。数据存本地 localStorage |
| 换手机数据迁移 | 「我的」→ 备份 JSON → 新手机导入 |
| 微信内打不开/定位失败 | 建议用系统浏览器打开链接；微信内定位慢时多点几次重试 |
| 想装成 APP | 用浏览器打开后「添加到主屏幕」（见第 5 节） |
| 部署更新 | git 提交新文件 push 到 main，Pages 自动更新 |
