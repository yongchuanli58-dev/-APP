## 第 0 步：先搞懂要做什么

咱们的应用是个**纯网页**，部署 = 把一堆文件放到 GitHub 上，GitHub 免费帮我们生成一个网址。

最终效果：
- 得到一个网址，如 `https://你的名字.github.io/broadband-leads/`
- 把这个网址发到微信群 / 生成二维码，任何人打开就能用
- 数据存在每个人自己手机里，互不干扰

**为什么你的高德 Key 用不了（重要）**：
你在高德控制台创建的 Key 是「**Web服务**」类型——它是给服务器程序用的，**不能在手机网页里定位**，所以它没有安全密钥（jscode）。
我们网页定位需要的是「**Web端(JS API)**」类型的 Key，**只有这种 Key 才会给你 jscode**。
所以第 2 步必须做，而且要在**新建应用**里创建「Web端(JS API)」类型的 Key。

## 第 1 步：注册 GitHub 账号

1. 浏览器打开 **https://github.com**
2. 点右上角 **Sign up**
3. 依次填写：
   - **Email**：你的邮箱（推荐用 QQ 邮箱 / 163 邮箱）
   - **Password**：设置密码（至少 8 位，建议字母+数字+符号组合，记牢）
   - **Username**：用户名（会出现在网址里，建议用拼音，如 `zhangsan2026`；**要独一无二**，被占用就换一个）
   - 完成后点 **Continue**
4. GitHub 会发一封验证邮件到你的邮箱，**打开邮件点绿色按钮 Verify email address** 完成验证
5. 回到 GitHub 会让你做一些选择题（目的调查），**直接跳过/选任意项**即可，看到主页面（左上角有你的头像）就是成功了

> 记下你的用户名，后面好几处要用。

---

## 第 2 步：新建高德「Web端(JS API)」Key（关键！）

你的旧 Key（Web服务）用不了，现在新建一个**专门给网页用**的 Key。

### 2.1 判断：你的高德账号是「个人开发者」还是「企业开发者」？

1. 打开 **https://console.amap.com/** 并登录
2. 进入「应用管理 → 我的应用」
3. 如果你的账号是**个人开发者**，理论上可直接创建「Web端(JS API)」Key；
   如果提示需要**实名认证**或**企业认证**，按页面提示先完成认证（个人实名用身份证+人脸，很快）。

### 2.2 新建应用

1. 在我的应用页面，点右上角 **创建新应用**
2. 应用名称填：`宽带商机`（随便起）
3. 应用类型选：**出行**（或按页面要求选一个，不重要）
4. 点 **新建**，应用创建成功

### 2.3 添加「Web端(JS API)」Key

1. 在刚创建的应用里，点 **添加 Key**
2. 按下面填：
   - **服务平台（服务类型）**：选 **「Web端(JS API)」** ⚠️ 一定不要选错！选「Web服务」就又白做了
   - **Key 名称**：`宽带商机-网页定位`（随便起）
   - **域名白名单（Referer 白名单）**：这里先**随便填一个占位**，比如 `https://example.com`（第 6 步会改成正式的）
     - 如果页面没有白名单输入框，就先不填
3. 点 **提交 / 保存**
4. 创建成功后，这一行 Key 的**右侧会出现两个值**，请都抄下来（复制保存到记事本）：
   - **Key**：一串 32 位字符（形如 `xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`）
   - **安全密钥（jscode）**：形如 `xxxxxxxxxxxxx_xxxxxxxxxxxxxxxxxxxxxx` 的一串字符
     - 有的界面安全密钥后面有「复制/查看」按钮，点一下展开复制

> ⚠️ **如果找不到 jscode**：请再截一张图给我，我看一下你的界面长什么样。

## 第 3 步：把新的 Key 和 jscode 填进项目

找到项目里的文件 **`config/amap-key.js`**，用记事本打开，改成：

```js
window.AMAP_CONFIG = {
  key: "这里填新的Key（32位字符）",
  securityJsCode: "这里填安全密钥jscode",
  timeout: 10000
};
```

**注意**：
- 引号别删，就替换引号中间的字符
- 如果你之前让我帮你填过那个「Web服务」Key（16c5fd...），**要把它换成新的**，别留旧的
- 如果第 2 步还没做、或 jscode 拿不到，**先别动这个文件**，继续做第 4 步也能先把网页部署出来（只是定位暂时不能用，之后再补）

## 第 4 步：在 GitHub 上建仓库并上传文件

### 4.1 新建仓库

1. 登录 GitHub，点右上角 **「+」→「New repository」**
2. 填写：
   - **Repository name**：`broadband-leads`（小写英文，照抄）
   - **Public / Private**：选 **Public** ⚠️（Private 仓库开 Pages 要付费）
   - 其他全部不要动（不要勾选 README）
3. 点绿色按钮 **Create repository**

### 4.2 上传项目文件（网页拖拽上传，不用命令行）

1. 创建好仓库后，会自动进入一个空仓库页面，上面有写着
   **"…or upload an existing file"** 的链接，点它
2. 此时打开你电脑上的项目文件夹（也就是这个 `商机收集APP` 里的项目目录，路径类似
   `C:\Users\24409\Desktop\商机收集APP\2026-11-17-10-53-34`），**文件夹窗口和浏览器并排显示**
3. 把下面**这些文件/文件夹**拖进浏览器上传区域：
   ```
   index.html
   css/（整个文件夹）
   js/（整个文件夹）
   config/（整个文件夹）
   ```
   > ⚠️ 不要上传：`node_modules`、`test/`、`package.json`、`.git`、`docs/` 里除 README 外的文档
   > （test 和文档只影响测试与说明，不影响网页运行；不传可以减少误操作）
4. 拖完后页面下方会有文件列表，点绿色 **Commit changes**

> 💡 如果你嫌上面选择困难，**最省事的办法**：把整个项目文件夹拖进去上传也行——只要别把 `node_modules`（一般不存在）传上去即可。网页正常运行只需要：`index.html` + `css/` + `js/` + `config/`。

## 第 5 步：开启 GitHub Pages（生成网址）

1. 进入你的仓库主页（刚传完文件会自动跳回）
2. 点顶部菜单 **Settings**（齿轮图标）
3. 左侧菜单往下找到 **Pages**（在 "Code and automation" 分组下）
4. 在 **Build and deployment** 区域：
   - **Source** 选 **Deploy from a branch**
   - **Branch** 选 **main**，右边目录选 **/ (root)**
   - 点 **Save**
5. 等待 1~3 分钟，页面顶部会出现一行绿字：
   `Your site is published at https://你的用户名.github.io/broadband-leads/`
6. **先自己验证**：手机或电脑浏览器打开这个网址，应该能看到「宽带线索商机」应用首页

> ⚠️ 打不开/白屏的排查：
> - 等够 3~5 分钟（首次发布较慢）
> - 确认仓库是 Public
> - 确认文件上传完整（index.html 是否在仓库根目录，不是嵌套在子文件夹里）
> - 若仍不行，截图仓库文件列表给我看

## 第 6 步：把部署域名加进高德白名单

> 这一步不做，手机定位会报错 `INVALID_USER_DOMAIN`。

1. 打开 **https://console.amap.com/** → 应用管理 → 我的应用
2. 找到第 2 步创建的那个「Web端(JS API)」Key，点右侧 **设置**
3. 找到 **域名白名单（Referer 白名单）** 输入框
4. 填入部署后的正式地址，**注意格式**：填到 `.github.io` 为止（不带后面的项目名）：
   ```
   https://你的用户名.github.io
   ```
   例如你的用户名是 `zhangsan2026`，就填：
   ```
   https://zhangsan2026.github.io
   ```
   > 为什么不带 `/broadband-leads`？高端白名单按域名（协议+域）校验，只要请求来源的主域名在白名单里即可，带项目名反而可能匹配不上。

   > 如果你以后绑定了自己的域名（如 `https://app.example.com`），还要把那个域名也加进去（多个白名单用英文逗号或换行分隔，看页面提示）。
5. 点 **保存 / 提交**

> 如果第 2 步没做（还没有 Web端 Key），那 jscode 也就还没有，定位暂时用不了；此时第 6 步可以顺延——但**建议按顺序先把 Key 建好**，一次到位。

## 第 7 步：真机验证与分享给同事

### 7.1 自己验证三件事
1. **打开**：手机浏览器（安卓用 Chrome / 系统浏览器，iPhone 用 Safari）打开你的网址
2. **定位**：进「录入」→ 点「打卡」→ 允许定位 → 显示地址（如果失败报 `INVALID_USER_DOMAIN`，回头查第 6 步；报 `INVALID_USER_SIGNATURE` 就是 jscode 没填对）
3. **导出**：随便录一条 → 「我的」→「导出 Excel 清单」，确认文件能打开、手机号显示正常（不是科学计数法）

### 7.2 分享给同事
- 方式一：把网址直接发到微信群/钉钉群
- 方式二：在「我的」页 →「分享给同事」→ 复制链接或系统分享

> 说明：分享为「链接 / 系统分享」方式，不生成二维码。需要给同事扫码时，可用手机浏览器「网页转二维码」功能。

同事打开后是**空白模板**，录入的数据只存在他手机，和你完全隔离 ✅

### 7.3 以后要更新怎么办
- 每次改了文件，重新上传覆盖同名文件（网页拖拽同一下）或者用 git push，Pages 会自动更新（1~3 分钟生效）
- 最简单：网页仓库页面 → 找到要改的文件 → 点小铅笔图标直接在线编辑 → Commit

## 第 8 步：安装为手机 APP（添加到主屏幕）

应用已支持 PWA，用浏览器打开后可以像原生 APP 一样**装到手机桌面**：全屏打开、带独立图标，以后点图标就能用，不用再输网址。

### 8.1 安卓（Chrome / 系统浏览器）
1. 用 **Chrome** 打开你的应用网址
2. 页面加载完，点右上角菜单（⋮）
3. 点「**添加到主屏幕**」（有的版本叫「安装应用」）
4. 确认名称「宽带线索商机」→ 点「添加」
5. 回到桌面，出现蓝色图标 → 点开就是独立全屏应用

### 8.2 iPhone（Safari）
1. 用 **Safari** 打开你的应用网址
2. 点底部「分享」按钮（方框 + 箭头）
3. 往下滑，点「**添加到主屏幕**」
4. 确认名称 → 点「添加」
5. 回到桌面，出现蓝色图标 → 点开全屏运行

### 8.3 小提示
- 首次装上后**建议联网打开一次**（把页面资源缓存下来），之后**断网也能打开**查看已录数据；定位/导航/导出仍需要网络，会正常提示
- 图标是蓝底白色宽带信号，跟应用主题一致；想换图标可替换 `assets/icon-192.png` 和 `assets/icon-512.png`（同尺寸 PNG）
- 数据仍存在**手机本地**，换手机/卸载前记得在「我的」页导出备份
- 微信里没有「添加到主屏幕」菜单，先右上角「在浏览器打开」再用浏览器装

## 常见问题 FAQ

| 问题 | 原因 | 解决 |
|---|---|---|
| 打开网址白屏 / 404 | 上传不完整 / 刚发布还没生效 | 等几分钟；确认 index.html 在仓库根目录；确认 Public |
| 定位报 INVALID_USER_DOMAIN | 高德白名单没配/域名不匹配 | 按第 6 步改白名单为 `https://用户名.github.io` |
| 定位报 INVALID_USER_SIGNATURE | jscode 没填/填错 | 检查 config/amap-key.js 里 securityJsCode |
| 定位一直转圈<br>或提示未配置高德Key | Key 类型不对（Web服务）或没填 | 确认用的是「Web端(JS API)」Key，别用「Web服务」Key |
| 微信里点打卡没反应 | 微信内定位受限 | 用系统浏览器打开，或在微信右上角「在浏览器打开」 |
| 怎么装成手机 APP | 正常行为 | 用浏览器打开后→「添加到主屏幕」（见第 8 步） |
| 同事打开是空的 | 正常！ | 分享的本来就是空白模板，各自存各自手机 |
| 手机换机数据没了 | 数据在旧手机本地 | 换前在旧手机「我的」→ 备份 JSON，新手机导入 |
| 想改文案/颜色 | 改 config/页面文件 | 上传覆盖后自动更新 |
