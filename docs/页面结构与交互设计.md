# 《宽带线索商机》页面结构与交互设计

> 版本：v0.1（设计稿）
> 适用：安卓 / iOS / 鸿蒙 手机浏览器或微信打开即用，免登录，数据本地存储
> 本文档描述第一版页面结构、页面内元素、操作流程与交互细节，供开发实现前确认。

---

## 1. 总体信息架构

```
《宽带线索商机》
├── 底部导航（4 个 Tab，始终可见）
│   ├── ① 商机首页（清单 + 概览）
│   ├── ② 录入（打卡 + 表单）
│   ├── ③ 统计
│   └── ④ 我的
│
├── 核心流程
│   ├── 录入流程：定位打卡 → 客户分类 → 在用运营商 → 套餐 → 客户信息 → 保存
│   ├── 跟进流程：清单 → 拨打客户 / 点击导航 / 查看详情
│   ├── 统计流程：按运营商 / 按资费区间 / 按客户类型
│   └── 分享流程：我的 → 分享空白模板 → 生成链接/二维码
│
└── 数据存储：浏览器本地（localStorage / IndexedDB），跨刷新、关闭、重启保留
```

---

## 2. 页面清单

| 编号 | 页面 | 导航位置 | 用途 |
|---|---|---|---|
| P1 | 商机首页 | Tab ① | 查看商机清单、快速搜索、今日概览、操作入口 |
| P2 | 商机录入 | Tab ② | 打卡定位 + 录入一条完整商机 |
| P3 | 商机详情 | 从 P1 进入 | 查看/编辑/删除单条商机 |
| P4 | 统计中心 | Tab ③ | 多维统计：运营商 / 资费区间 / 客户类型 / 时间段 |
| P5 | 我的 | Tab ④ | 数据管理、分享模板、关于/帮助 |
| P6 | 分享预览 | 从 P5 进入 | 分享前预览空白模板、生成分享链接/二维码 |
| P7 | 引导/空态页 | 全局 | 首次使用说明、无数据提示、加载失败提示 |

**页面间跳转关系**

- 首页 P1 ⇄ 录入 P2（底部 Tab 直达）
- 首页 P1 → 详情 P3（点击单条商机）
- 详情 P3 ⇄ 录入 P2（编辑现有商机）
- 首页 P1 → 统计 P4（底部 Tab）
- 我的 P5 → 分享预览 P6
- 首次打开 → 引导 P7 → 首页 P1

## 3. 页面详细设计

### 3.1 P1 商机首页

**定位**：进入 APP 后的默认页面，商机清单 + 轻量概览。

**顶部区域**
- 页头：标题「宽带线索商机」；右侧入口：搜索按钮、更多按钮
- 概览卡片（3 个数字，横向排布）：
  - 今日线索（今天录入条数）
  - 本周线索
  - 线索总数（累计）
- 快捷入口指示：点击「录入」Tab 进入新商机录入

**清单列表**
- 数据来源：本地存储中的全部商机，默认按录入时间倒序
- 列表项卡片（一条商机一张卡）展示字段：
  - 客户名称（主标题，加粗）
  - 客户类型徽标（政企 / 中小企 / 个体 / 家庭，彩色小标签）
  - 在用运营商徽标（移动 / 联通 / 电信 / 广电，可显示多个）
  - 资费金额（如「68 元/月」）
  - 定位地点（打卡得到的地址文本）
  - 录入时间（相对时间：刚刚 / 3 分钟前 / 昨天）
- 每张卡片右侧 2 个操作按钮（图标 + 文字）：
  - **拨打客户**（电话图标）：点击弹确认 → 调起系统拨号盘，号码自动带入
  - **点击导航**（导航图标）：点击弹确认 → 打开高德地图 App 或网页导航到该客户位置
- 点击卡片主体（除按钮外区域）→ 进入详情页 P3

**列表操作**
- 下拉刷新：重新核对本地数据（刷新列表排序、同步概览数字）
- 搜索：顶部搜索框，支持按「客户名称 / 电话 / 地点」关键字过滤
- 过滤条件（顶部横向滑动）：
  - 全部 / 今天 / 本周 / 已回访 / 未回访
- 空状态：无数据时显示提示卡片「还没有商机，点下方【录入】开始记录第一条」

**交互细节**
- 列表懒加载：先加载最近 50 条，滚动到底自动加载更多
- 左滑删除（移动端手势）：清单项左滑露出「删除」，二次确认后删除

### 3.2 P2 商机录入

**定位**：核心录入页，通过底部 Tab「录入」进入，可从详情页切换为编辑模式。

**页面结构（从上到下）**

1. **定位卡片（打卡）**
   - 初始态：显示「点击打卡定位」按钮 + 定位图标
   - 点击后：调用高德地图定位（浏览器 Geolocation API）
     - 授权弹窗：请求位置权限（iOS 需要用户允许）
     - 定位成功：显示「已定位」，展示 省市区 + 详细地址 + 定位时间，右侧打卡成功后变「绿色已定位」状态
     - 定位失败：显示「定位失败，点击重试」；仍允许手动编辑地址文字
   - 地址编辑：定位成功后可点击地址字段手动微调（比如「3 号楼东侧门口」）
   - 重新打卡：已定位后可再点一次刷新定位

2. **客户类型（单选，必填）**
   - 4 个选项卡片，点选高亮：政府事业单位 / 中小企业 / 个体工商户 / 个人家庭
   - 默认无选中，进入页面即需选择一项，未选无法保存

3. **客户业务当前使用情况（多选，可空）**
   - 标题：「当前在用运营商（可多选）」
   - 4 个选项：移动 / 联通 / 电信 / 广电，方形勾选框多选
   - 备注文字：不选表示该客户目前没有在用宽带/专线（纯新客户）

4. **客户当前使用资费（可选填）**
   - 套餐名称：文本框，如「移动 200M 家庭宽带」
   - 套餐金额：数字键盘输入，单位「元/月」，只允许非负数字
   - 不填表示暂未知

5. **客户信息（必填部分）**
   - 客户名称：文本框（必填）
   - 联系电话：手机键盘输入（必填，11 位手机号校验）
   - 性别：单选（男 / 女，不填留空）
   - 回流意愿：单选（强烈 / 一般 / 暂无），用于标识营销优先级，可留空
   - 备注：多行文本框（可空，最多 500 字），随时记录重要客户信息（如偏好、预约、跟进要点）

6. **底部提交栏（固定定位，不随滚动消失）**
   - 左侧：已填字段完成度提示（如「已填 4/7」）
   - 右侧：「保存商机」主按钮
   - 保存校验：必填项（客户类型、客户名称、电话）未填完整 → 红字提示并定位到未填项
   - 保存成功：toast「已保存」，自动跳回首页 P1，列表顶部可见新记录

**交互细节**
- 表单全部内容单页承载，避免多步分页（减少一线师傅操作成本）
- 电话号码：调起数字拨号键盘（`type="tel"`）
- 金额：调起数字键盘，正则校验非负数字，最多 2 位小数
- 打卡定位与表单填写无顺序依赖：可以先填信息再打卡，也可以先打卡
- 失败兜底：任何一项（定位等）失败都允许「跳过 + 手填」，不阻断录入

### 3.3 P3 商机详情

**定位**：查看单条商机完整信息，支持编辑与删除。

**页面内容（从上到下）**
1. 头部：客户名称 + 客户类型徽标
2. 关键信息卡片
   - 在用运营商（徽标组合）
   - 套餐名称 / 套餐金额 / 月费
3. 客户信息卡片
   - 联系电话（显示 + 「拨打」按钮）
   - 性别
   - 回流意愿
   - 备注（有内容才展示）
4. 位置信息卡片
   - 打卡定位得到的地址
   - 「点击导航」按钮（打开高德导航到该客户）
   - 定位时间
5. 记录信息：录入时间、来源
6. 底部操作栏
   - 「编辑」：进入录入页 P2（预填当前数据，标题改「编辑商机」）
   - 「删除」：二次确认（弹窗「确定删除这条商机？」），确认后回到首页列表移除
   - 「分享单条」（可选保留项）：生成该客户名片文本，可复制发微信

---

### 3.4 P4 统计中心

**定位**：多维统计，供下周/下月及持续营销参考。

**页面结构**

1. **运营商分布统计（卡片）**
   - 4 个数值块：移动 / 联通 / 电信 / 广电（在用条数）
   - 环形占比图（可选）：直观展示份额
   - 说明文字：因允许多选，条数之和可能大于客户总数，标注「含多运营商客户」

2. **资费区间统计（自定义）**
   - 上方：区间输入条（起止金额两个数字输入框）+「开始统计」按钮
   - 下方：统计结果卡片
     - 区间内线索条数
     - 区间内金额合计（月费总额）
     - 区间内平均月费（保留 2 位小数）
     - 区间明细列表（列出该区间内每个客户的名称 + 月费，点击可进详情）
   - 交互记忆：最近 5 次查询的区间保留在快捷选择栏，可一键复用（「50-100」「100-200」「200+」等）

3. **客户类型分布统计**
   - 4 类客户条数 + 占比（政企 / 中小企 / 个体 / 家庭）

4. **时间维度统计**
   - 本周录入条数 / 本月录入条数 / 今日录入条数（3 个数字块）
   - 简单趋势条（近 7 天每日录入数，条形图）

5. **导出按钮（常驻底部）**
   - 「导出 Excel」：将当前统计范围或全部清单导出为 Excel 文件（对应功能模块，见 4.4）

**交互细节**
- 全部统计只读；数据变动（新增/删除商机）后，重新进入统计页自动刷新
- 数字一律千分位格式化展示；金额保留 2 位小数

### 3.5 P5 我的

**定位**：个人数据管理 + 分享入口。

**页面结构（从上到下）**

1. **账号/身份卡**
   - 免登录设计，显示本地标识（如「本机商机库」）
   - 显示本机数据统计：商机总数 / 覆盖客户数 / 本月录入数

2. **分享模板入口（重要）**
   - 卡片：「分享给同事」
   - 说明文字：『把空白商机模板分享给同事，他/她可获得一个全新的、带全部功能但商机清单为空的版本；你的商机数据不会随分享发出。』
   - 点击 → 进入 P6 分享预览页

3. **数据管理**
   - 「导出 Excel」：导出本机全部商机清单 → 触发下载（见 4.4）
   - 「数据备份」：导出为 JSON 备份文件（可选）
   - 「导入备份」：从 JSON 恢复（可选）
   - 「清空全部数据」：危险操作，需输入「清空」确认 + 二次弹窗

4. **使用方法/帮助**
   - 新手引导（重新播放）
   - 使用说明（图文）
   - 常见问题 FAQ

5. **关于**
   - 版本号、更新说明、联系方式、免责声明

**交互细节**
- 备份/导入可选做，第一版可隐藏；先保导出 Excel
- 清空数据为最高危操作，必须二次确认 + 文字输入确认

---

### 3.6 P6 分享预览

**定位**：生成“空白模板”分享内容，供同事打开使用。

**页面内容**

1. **预览卡片**
   - 显示分享出来的样子（简化示意：图标 + 名称「宽带线索商机」+ 一句话简介「一线师傅专用商机收集工具」）
   - 明确标注「空白模板 · 商机清单为空」

2. **分享方式**
   - 方式 A：微信二维码（长按识别打开）
   - 方式 B：复制链接（点按钮复制 URL，粘贴到微信/钉钉发送）
   - 方式 C：更多分享（调起手机系统分享面板）

3. **安全说明（静态文案）**
   - 「同事打开后将看到全新的空白商机库」
   - 「您的商机数据存放在您自己的手机，不会因分享而泄露」

**交互细节**
- 二维码由链接实时生成（前端生成，无需服务器）
- 每个访问用户是独立存储空间（同一个链接不同人看到的是各自的数据）

### 3.7 P7 引导 / 空态 / 异常页

**引导页（首次打开）**
- 3 张引导卡片可滑动：① 这是什么 ② 怎么录商机（打卡+表单） ③ 数据存哪（本机）
- 「立即开始」按钮 → 进入首页 P1
- 首次进入也自动生成各人独立的本地存储键（保证不串数据）

**空态页**
- 清单无数据：插画 + 「还没有商机，点下方【录入】开始记录第一条」
- 统计无数据：插画 + 「录入商机后可查看统计」
- 搜索无结果：插画 + 「没有找到相关商机」

**异常页**
- 定位失败：提示重新授权 + 手动填写地址兜底
- 本地存储不可用（如隐私模式）：提示改用请使用普通模式浏览
- 系统拨号/导航不可调用：提示手动操作

## 4. 关键交互流程（时序化描述）

### 4.1 新录一条商机（主链路）

```
打开 APP（首页）
  → 点击底部【录入】
  → 进入录入页（P2）
  → 点击【打卡定位】→ 授权 → 定位成功显示地址
  → 选择客户类型（政府/中小企/个体/家庭）
  → 勾选在用运营商（可多选）
  → 填套餐名称、套餐金额
  → 填客户名称、电话、性别、回流意愿、备注
  → 点击【保存商机】
     （校验必填项 → 通过）
  → 提示「已保存」→ 自动回首页，新记录出现在列表顶部
  → 概览数字 +1，统计页下一次打开自动更新
```

### 4.2 从清单拨打客户

```
首页清单
  → 某条卡片点【拨打客户】
  → 弹确认：「拨打 138xxxx1234？」（确认 / 取消）
  → 确认 → 调起系统拨号盘，号码自动带入
  → 用户确认呼出
```

### 4.3 从清单导航到客户

```
首页清单
  → 某条卡片点【点击导航】
  → 弹确认：「使用高德导航前往该客户？」
  → 确认 → 打开高德（App 优先，未装则网页版）→ 定位客户打卡坐标导航
```

### 4.4 导出 Excel

```
「我的」或「统计页」点【导出 Excel】
  → 读取本机全部商机（或当前统计范围）
  → 前端生成 .xlsx 文件（列：客户名称/类型/运营商/套餐名/金额/联系人/电话/性别/回流意愿/备注/地址/定位时间/录入时间）
  → 触发浏览器下载
  → 用户可在文件管理器 / 微信中转发 Excel
```

### 4.5 分享空白模板给同事

```
「我的」点【分享给同事】
  → 进入分享预览（P6）
  → 生成分享链接 + 二维码
  → 选择方式：微信扫码 / 复制链接 / 系统分享
  → 同事打开链接 → 首次进入引导页 → 建立自己的空白库
  → 同事录入自己的商机 → 与你的数据完全隔离
```

### 4.6 数据隔离机制（关键设计）

| 场景 | 数据表现 |
|---|---|
| 同一手机不同人使用 | 共用本地存储（同一设备），暂不做多人账号隔离（可按需后续加） |
| 不同手机（同事 A / B） | 各自手机各自存储，互不可见 |
| 分享链接 | 打开即用新空库，不携带任何源数据 |
| 刷新 / 关闭 / 重启 | 数据保留（本地持久化） |
| 卸载浏览器数据 / 清网站数据 | 数据丢失（告知用户导出 Excel 备份） |
