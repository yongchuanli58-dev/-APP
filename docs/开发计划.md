## 0. 开发原则与交付物

| 项 | 说明 |
|---|---|
| 技术形态 | 纯前端单页应用（SPA），无后端服务器，无数据库 |
| 数据存储 | 浏览器 localStorage / IndexedDB（本地持久化） |
| 兼容目标 | 安卓（Chrome/微信）、iOS（Safari/微信）、鸿蒙（浏览器/微信）；屏幕 320–430px |
| 定位 | 高德开放平台 JS API（Web Key 已申请） |
| 分享 | 静态托管平台（首选 GitHub Pages）承载链接 + 前端生成二维码 |
| 最终交付物 | 可运行的静态站点文件 + 部署步骤文档 |

## 1. M0 环境准备与项目脚手架

### 1.1 技术选型确认

| 项 | 选型 | 理由 |
|---|---|---|
| 框架 | 原生 HTML/CSS/JS + 轻量 MVVM（可选 Vue3 CDN 或纯原生） | 无构建依赖、可直接静态托管、三端兼容性好 |
| 图标 | Font Awesome 或内联 SVG | 避免额外依赖体积 |
| 本地库 | 单一 `store.js`（封装 localStorage） | 数据层统一 |
| 二维码 | 高德/URL 拼接 + 系统分享（零依赖） | 分享页复制链接/系统分享，不备份生成 |
| Excel | 零依赖自实现 OOXML(.xlsx) + CSV（`js/utils/export.js` 手写 ZIP） | 内网无法下载 SheetJS，纯前端生成标准 .xlsx |
| 地图 | 高德 JS API（已申请 Web Key） | 打卡定位 + 导航 |
| 构建 | 无（纯静态） | 直接部署 |

## 2. M1 数据层与本地存储

### 2.1 数据模型（对齐 PRD 6.2）

```js
// 单条商机
{
  id: "uuid v4 或时间戳+随机",
  createTime: "ISO 时间戳",
  updateTime: "ISO 时间戳",
  clientType: "government|sme|individual_business|home",
  carriers: ["移动","联通"],        // 多选
  packageName: "套餐名（可空）",
  packageFee: 68,                   // 数字，可空
  customerName: "客户名称（必填）",
  phone: "13800138000（必填）",
  gender: "男|女",
  remark: "备注（可选，自由文本，最多500字）",
  returnIntent: "强烈|一般|暂无|''",
  location: {
    address: "省市区+详细地址",
    lng: 116.397, lat: 39.908,
    locatedAt: "定位时间"
  }
}
```

### 2.2 store.js 接口设计

| 方法 | 说明 |
|---|---|
| `add(lead)` | 新增，生成 id/createTime，返回 id |
| `update(id, patch)` | 更新指定商机，更新 updateTime |
| `remove(id)` | 删除（软删/硬删，第一版硬删） |
| `get(id)` | 查询单条 |
| `list({filter, keyword, sort})` | 查询列表，支持筛选/搜索/排序 |
| `stats()` | 聚合统计（按运营商/类型/时间） |
| `clearAll()` | 清空全部（二次确认后调用） |
| `exportAll()` | 导出全量数组（用于 Excel） |

### 2.3 存储键名与隔离

- 主键：`bx_sj_v1_leads`（数组）或 `bx_sj_v1_leads_<userId>`（预留多用户）
- 首次打开生成本机标识 `bx_sj_v1_device_id`（随机 UUID），存入 localStorage
- 每个设备独立空间 → 天然实现「不同用户数据隔离」

- [ ] 控制台可增删改查一条模拟商机，刷新后仍在
- [ ] 无痕模式打开显示提示「不保存数据」（PRD 5.4-8）
- [ ] 存储容量：预估单条 < 1KB，localStorage 5MB 可存数千条；超限自动降级提示或转 IndexedDB（第一版做到提示即可）

## 3. M2 底部导航与全局框架

### 3.1 全局布局

```html
<div id="app">
  <div id="page-container"><!-- 各页面视图 --></div>
  <nav id="tabbar">
    <button data-route="home">① 商机</button>
    <button data-route="input">② 录入 ➕</button>
    <button data-route="stats">③ 统计</button>
    <button data-route="mine">④ 我的</button>
  </nav>
</div>
```

- 固定底部、顶部安全区适配（`env(safe-area-inset-*)`）
- 路由：hash 路由（`#/home`、`#/input`、…），无需服务器配置（PRD 2.4）
- 页面视图用 JS 渲染（模板字符串 + 事件委托），不引入大型框架

### 3.2 页面容器与切换

- 每个页面视为一个 render 函数：`renderHome()`, `renderInput()`, …
- 切换 Tab → router 更新 hash → 对应 render 替换 `#page-container` 内容
- 录入页从详情「编辑」进入时，hash 携带商机 id：`#/input?id=xxx`，页面读取预填

### 3.3 里程碑出口（验收）

- [ ] 4 个 Tab 可互相切换，页面内容对应变化
- [ ] 底部 Tab 在安全区适配下不被遮挡
- [ ] 刷新后停留在当前 hash 对应页面

```
│ 客户类型（4 选 1，必填）       │
│  政府事业单位|中小企业|个体|家庭│
├────────────────────────────┤
│ 在用运营商（多选，可空）        │
│  ☐移动 ☐联通 ☐电信 ☐广电     │
├────────────────────────────┤
│ 使用资费                      │
│  套餐名称[____] 金额[____]元/月│
├────────────────────────────┤
│ 客户信息                     │
│  名称[*____] 电话[*____]     │
│  性别 ○男 ○女                    │
│  回流意愿 强烈/一般/暂无        │
│  备注[________________]      │
├────────────────────────────┤
│ [保存商机]                    │
└────────────────────────────┘
```

### 4.2 打卡定位交互（amap.js）

| 步骤 | 行为 |
|---|---|
| 点击「打卡定位」 | 调用高德 JS API 定位（`AMap.Geolocation`） |
| 权限询问 | 浏览器弹出位置授权（首次） |
| 成功 | 显示 省市区+详细地址+定位时间；地址可点击手动微调 |
| 失败 | 显示「定位失败，点击重试」；允许手动填地址，不阻断保存 |
| 已定位 | 按钮变「📍已定位」，可再次点击重新定位 |

- 高德 Key 从 `config/amap-key.js` 读取（实现时注入 window 配置，避免硬编码在主页）
- 安全密钥（jscode）一并配置

### 4.3 表单校验（validate.js）

| 字段 | 规则 |
|---|---|
| 客户类型 | 必填（4 项未选拦截） |
| 客户名称 | 必填，非空 |
| 电话 | 必填，正则 `/^1\d{10}$/`（大陆手机号），键盘 `type=tel` |
| 套餐金额 | 可选，数字，`/^\d+(\.\d{1,2})?$/`，拒绝负数/字母 |
| 性别/回流意愿 | 可选，单选（默认未选） |
| 备注 | 可选，自由文本，最多 500 字 |

- 校验失败：字段红框 + 下方错误文案，并滚动定位到首个未填项

### 4.4 保存流程

```
点击保存
→ 校验必填
→ 通过：store.add 或 store.update
→ toast「已保存」→ 跳回 #/home（列表刷新，新记录置顶）
→ 失败：红字提示，不丢已填内容
```

- 点击卡片主体 → `#/detail?id=xxx`
- 左滑手势：支持 touchstart/touchmove，右滑露出左滑「删除」按钮（二次确认）

### 5.4 拨打客户


### 5.5 点击导航

```
点击[导航] → 弹确认「使用高德导航前往该客户？」
→ 确认 → 优先尝试调起高德App:
   uri = "androidamap://navi?sourceApplication=appname&lat=..&lon=..&dev=0"
   失败(未安装) → 打开高德网页导航:
   https://uri.amap.com/navigation?to=lon,lat,名称&coordinate=gaode&mode=car
```

### 7.2 运营商统计

- `store.stats()`：遍历全部商机，对 `carriers` 数组逐项计数（一条多选在多家各计一次）
- 展示 4 个彩色数字块 + 份额条；底部小字说明「含多运营商客户，条数和可大于商机总数」

### 7.3 资费区间统计（核心）

| 步骤 | 逻辑 |
|---|---|
| 输入起止金额 | 两个数字输入框，校验数字、起≤止 |
| 点开始统计 | 过滤 `packageFee >= 起 && <= 止` 的商机（空金额不纳入） |
| 结果 | 条数、月费合计（Σ）、均值（保留 2 位）、明细列表（名称+金额，点击进详情） |
| 最近查询 | 存入 localStorage 最近 5 条区间，快捷 chips 一键复用 |

### 7.4 客户类型 / 时间统计

- 客户类型：4 项各自计数 + 占比
- 时间：今日/本周/本月录入数；近 7 天每天条数 → 纯 CSS 条形图
- 本周起点用周一（`time.js` 计算）

### 7.5 数据联动

- 每次进入统计页触发 `store.stats()` 重算（PRD 5.3-6）
- 导出按钮复用 `export.js`

## 9. M8 导出 Excel（零依赖自实现）

### 9.1 实现

> 背景：内网无法下载 SheetJS 等外部库，故改为纯前端自实现标准 .xlsx（OOXML + 手写 ZIP，STORED 不压缩），离线可用。

| 步骤 | 逻辑 |
|---|---|
| 收集数据 | `store.exportAll()` 全部商机 |
| 转换行 | 按 PRD 6.1 的 12 列顺序生成行数组 |
| 生成文件 | 手写 OOXML XML 部件 → `zipStore()` 打包（CRC32 + local/central header + EOCD）→ `exportXlsx(leads)` 返回 ArrayBuffer |
| 下载 | 浏览器触发下载（Blob + a.download），文件名 `宽带线索商机_YYYY-MM-DD.xlsx` |
| 电话保护 | 联系电话列强制 `inlineStr` 文本，防止被 Excel 转成科学计数法 |
| CSV 备选 | `exportCsv()` 同逻辑输出 UTF-8 BOM 编码 .csv |

### 9.2 列映射（对齐 PRD 6.1）

```
客户名称 | 客户类型 | 在用运营商 | 套餐名称 | 套餐金额(元/月) |
联系电话 | 性别 | 回流意愿 | 备注 | 地址 | 定位时间 | 录入时间
```

- 运营商多选 → 「移动、联通」以顿号/逗号分隔一格
- 客户类型/回流意愿 → 中文（未选填「空」）
- 备注 → 客户备注原文（未填为空）
- 金额 → 数字（保留 2 位小数或原样）
- 当前导出函数：`js/utils/export.js`（`exportXlsx` / `exportCsv`，UMD 导出供浏览器与测试共用）

### 9.3 里程碑出口（验收）

- [x] PRD 5.4 中 4.1–4.3 全部通过（真机下载、WPS/Excel/手机表格打开、电话列非科学计数法、多选分隔）
- [x] 全量测试 `test/m8-export.test.js`（10 例）通过：ZIP 魔数 PK、OOXML 条目、电话 inlineStr 保护、CRC32 标准值、XML 转义

## 13. 风险与应对

| # | 风险 | 影响 | 应对 |
|---|---|---|---|
| 1 | 微信内定位被拦截（尤其 iOS） | 打卡失败 | 高德 JS API + 明确授权引导；失败兜底手填地址（PRD 已定） |
| 2 | 免费海外托管国内访问慢/不稳 | 打开卡顿 | 首选静态化小体积、启用 CDN；彻底不行迁移公司服务器 |
| 3 | 高德 Key 泄露 / 域名白名单缺失 | 定位失效 | Key 独立配置 + 白名单；文档明确配置步骤 |
| 4 | localStorage 5MB 上限（数千条后） | 录入失败 | 单条压缩存储；超限提示导出备份并转 IndexedDB（第二版） |
| 5 | 手机浏览器清缓存丢数据 | 数据丢失 | 引导页提醒定期导出备份；「我的」提供导出 Excel/JSON |
| 6 | 内网无法下载 SheetJS 等库 | 导出无法用现成库 | 已改为零依赖自实现 .xlsx（手写 ZIP + OOXML），无外部加载，首屏/导出均无额外体积 |
| 7 | 各机型微信 webview 差异 | 拨号/导航不可用 | 降级处理：toast 提示「请手动拨打/导航」，不崩溃 |
